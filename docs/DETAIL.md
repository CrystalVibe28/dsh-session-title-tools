![A session title settings page with mode, model, and prompt length controls](preview.svg)

The page switches DSH's shipped `first-prompt` / `all-prompts` title providers,
pins the title model, and sets the native prompt length targets. The mode control
toggles the shipped experimental bundle over the native plugin-manager remote and
reports the real outcome; a manual switch on DSH's Plugins page is respected. The
model and length controls project onto whichever provider row is running.
